“+” button for desktop Safari and Chrome

Drag this to your bookmarks bar, then click it on any page: +
It opens the add form in a new tab, which closes itself when you save or cancel.

Open this page from its GitHub Pages address first. The “+” button has to point at a web address, not a local file.

“+” on iPhone and iPad

  1. In the Shortcuts app, create a shortcut named + Bookmark and turn on Show in Share Sheet (accept URLs and Safari web pages).
  2. Add the action URL Encode with Shortcut Input.
  3. Add the action Open URLs with: followed by the URL Encoded Text variable.

Then share any page from Safari or Chrome and pick + Bookmark.
